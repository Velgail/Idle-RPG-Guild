## 決定ログ（Decision Log）
- ✅ **D-01 勝敗/進行**: 物語は後付け。**唯一の終わり＝「バランスの破局」**。コアは無限の耐久ホメオスタシス。勝利エンドは無く、プレイヤーは壊れるまで保ち続ける（スコア＝生存地平＋効率）。
- ✅ **D-02 ガンビット深度**: **硬派より**（Zach系プログラミングを主要な歯ごたえに）。
- ✅ **D-03 8ボール**: **秘匿チャネル＝プレイヤー定義の暗号**。意味は創発的にプレイヤーが決める。
- ✅ **D-04 時間モデル**: **まずセッション型**（開いている間に tick が進む／PC寄り）。後にハイブリッド。
- ✅ **D-05 魔王軍の実体**: **プレイヤーが「ボール盤面 → 魔王軍ルーチン」の応答表を組む**。魔王軍の挙動は literal なコード。§8 の分散システム像が本物になる。
- ✅ **D-06 秘匿性の扱い**: **構造的（カバーストーリー型）**。疑念を測る常時監視ゲージではない。8ボードの表の用途＝「勇者を呼ぶ盤」が正当に存在するので、裏の魔王協調がその隠れ蓑として成立する。「疑われないためにボールを使っている」。
- ✅ **D-07 エントロピー**: **多源・生きた世界**。冒険者の成長/死、人口増・街の拡大、魔王のダンジョン拡張、経済変動、ダンジョン産アイテムの強化、旨味低下による離散……多数の成長過程が絡み、静的マニュアルはいずれ破綻する。

- ✅ **D-08 コアゲージ**: **循環 / 利潤 / 攻略進捗 の3本**。人口・街規模は「循環」に内包。疑念は常時ゲージではない（D-06）。
- ✅ **D-09 HALT＝勇者緊急呼び出しモード**: 盤面の置き方で「緊急呼び出し」を武装できる。発火すると**1〜5分以内にゲーム進行が一時停止**（＝勇者が到着した瞬間）。停止中がプレイヤーの**手動オペレーション窓**：直接操作したり、**新しいガンビット・マニュアルを差し替え（持ってきて投げる）**たりする。再開＝勇者が去り自動運転に戻る。→ §3「たまに覗いて手直し」ループの機構的実装。普段は自由に触れず、**呼ばれたときだけ**重い介入をする（edit→run のZach的リズム）。
- ✅ **D-10 拡張スパイン（進行）**: 制約はルール枠＋バス帯域の**両方**。加えて時間で拡張する:
  - **秘書の成長**（処理できるルール枠が増える）
  - **秘書の複数化**（規模が上がると秘書を増員。各自が担当ドメインのマニュアルを持つ → 秘書間の協調も puzzle に）
  - **ボール帯域の拡張**（使えるスロットが序盤は少なく、**最大8**まで解禁）
  - → D-07 の増大するエントロピーに対抗して装置を拡張する競争が、放置ゲーの進行軸になる。

### 8ボードの確定モデル（D-03/D-05/D-06 の統合）
一枚の8スロット盤が**三役**を同時に担う:
1. **表: 勇者を呼ぶ盤** — 原案「勇者に連絡を入れるための8つ」。秘書は「マスターを呼ぶ符丁」と納得（実際に或る盤面で勇者が来るので筋が通る）。
2. **裏: 魔王への制御符号** — 魔王も同じ盤を読み、応答表で動く。表の正当用途が裏の談合のカバーになる。
3. **再関与の割り込み** — 「今、人間の判断が要る」盤面がプレイヤーを呼ぶ＝§3ループの発火装置。

## 1. ワンライナー

**「完璧に自動化したはずのギルドが、世界の揺らぎで少しずつズレていく。勇者は最小限の手直しだけで、永遠の均衡（=世界の循環）をこっそり保ち続ける。」**

ジャンル: 放置 × 自動化プログラミング（ガンビット）× 恒常性維持（ホメオスタシス）× 秘匿協調。

## 2. 物語の骨子（Director原案の要約）

- 勇者と魔王は最終決戦で「魔王という存在が実は世界の循環に貢献していた」と気づく（気づかせる）。
- 討伐したことにして、**永遠に世界の循環を回す方法**を模索。
- ダンジョンで人を集め・衝突させることで世界のバランスが取れると判明。
- 勇者 → **ギルドマスター**、魔王 → **ダンジョンマスター**。協力して「人間世界の利潤」と「世界の循環」を両立し、**ダンジョンを永遠に攻略させない均衡**を保つ。
- ギルドマスターの仕事はマニュアル化すると**秘書**が全部正しく代行する。勇者はサボって悠々自適（魔王といい関係に）。

---

## 3. 設計の核心的パラドックス（最重要）

> **物語の理想＝「完璧に自動化して何もしないこと」。しかしゲームは、プレイヤーが関与しないと成立しない。**

ここを解かないと「うまくいくほど遊ぶ理由が消える」ゲームになる。PMの提案する解決の方向：

**コアループ＝「例外処理 / 秘匿ホメオスタシス」**
1. 世界は常にドリフト（自然な偏り）とノイズ（突発イベント）を生む。
2. 現行マニュアル（ガンビット）は「想定外」を完璧には捌けない → ゲージがバンドから外れ始める。
3. プレイヤーは**時々**様子を見て、「何がズレたか」を診断 → マニュアル/ボール/魔王軍ルーチンを**高レベルに手直し**。
4. 安定 → 新しい変数（新種の冒険者、新フロア、新しい経済圧）が解禁 → 旧マニュアルが壊れる → 2へ。

→ 「サボる勇者」の気持ちよさ＝**逐次マイクロ操作をしないこと**。やるのは「たまの方針編集」だけ。エンゲージメント＝**自分の自動化をデバッグする快感**。

## 4. システムの柱（現時点の解釈 / 要確認）

### 4.1 ガンビット（秘書へのマニュアル）
- FF12的な「条件 → 行動 / 優先度順」ルール群。ゲームの**主要な深さ**候補。
- 秘書は忠実だが、**勇者と魔王が結託していることを知らない**。
  - → これは単なるフレーバーか？ それとも「秘書に見える形で露骨な談合はできない」という**機構的制約**か？（後者だと面白い）

### 4.2 8つのボール置き場 ← ユニーク機構
- **PM解釈: これは「秘匿チャネル（covert channel）」ではないか。**
  - ギルドの表向きは秘書がマニュアルで透明に回す。だが勇者と魔王は、秘書にも見える無害な見た目のボール配置に**暗号的な意味**を載せてマッチポンプを協調する。
  - 8スロットの制約＝**低帯域・観測可能な通信路**。「魔王も見れる」＝共有ブラックボード。
- 未確定: 書き込むのは誰？（勇者だけ / 双方向）／ボールの種類・色・意味は**プレイヤー定義**か固定機能か／リアルタイムの主要動詞はこれか。

### 4.3 魔王 / 魔王軍
- 魔王は**大雑把な指示**のみ。ボール置き場の状態に応じて魔王軍のあり方を変更。
- 魔王軍のルーチン変更は**1日1回**（低頻度・粗い操作）。
- 未確定: 魔王は「プレイヤーが操るもう一つの卓」か「ボールに反応する半自律AI」か。ルーチンの語彙（攻撃性 / モンスター種 / フロア構成 / 難度）。

### 4.4 HALT
- ボールの置き方に対して HALT できる。
- 未確定: 全自動の緊急停止か / 特定ボールへの拒否権か / 一時停止か。誰がHALTできるか（勇者・魔王・秘書）。コストとリスク。

### 4.5 ゲージ（均衡の対象）※候補
- 世界の循環（メイン） / ギルド利潤 / 冒険者人口 / ダンジョン難度（攻略進捗）/ 秘匿度（秘書にバレない度合い）。
- 各ゲージに「安全バンド」。長時間外れると失敗。

## 8. v0.2 — 決定から導かれるアーキテクチャ

D-01〜D-04 を素直に伸ばすと、このゲームの正体は **「観測可能で狭い共有バスを介して、両端を自分でプログラムする分散システムを、崩壊するまで保ち続ける」** ゲームになる。

### 8.1 二つの半分＋一本のバス
```
   ┌──────────────┐        8ボール・バス        ┌──────────────┐
   │  ギルド側     │  ← 秘書にも見える共有状態 → │  ダンジョン側 │
   │ 秘書/ガンビット│  ── プレイヤー定義の暗号 ──> │  魔王軍       │
   │ (透明・高頻度) │                            │ (粗い・1日1回)│
   └──────────────┘                            └──────────────┘
      冒険者・募集・編成・報酬            モンスター配置・難度・ドロップ
```
- **ギルド側**: 冒険者の募集/編成/派遣/報酬/引退をガンビットで自動運用。透明・高頻度。
- **ダンジョン側**: モンスター配置・難度・報酬を制御。**バスを読んで 1日1回だけ**ルーチンを切替。
- **8ボール・バス**: 両半分をつなぐ唯一の線。プレイヤーが「ボール配置パターン → ダンジョン挙動」の**符号（コード）を自作**する。
  - ここが D-02(硬派) と D-03(暗号) の交点。プレイヤーは実質 **命令セット（ISA）／制御プロトコルを設計**する。8スロットの状態空間と「1日1回」の低帯域が、圧縮と表現力のパズルを生む。

### 8.2 コアゲージ（バンドを外れたら破局）※提案
| ゲージ | 上がりすぎ | 下がりすぎ |
|---|---|---|
| **循環 Flux**（冒険者の衝突/回転） | 消耗で人口クラッシュ | 世界が停滞＝循環破綻 |
| **利潤 Profit**（ギルド経済） | （過剰は疑念の種？） | 破産 |
| **攻略進捗 Clear**（ダンジョンが突破される距離） | **100%＝攻略される（最悪の破局）** | 低すぎるとつまらず人が去る→循環↓ |
| **疑念 Suspicion**（秘書の気づき） | **MAX＝結託露見（破局）** | — |

**中心の緊張**: 循環・利潤は「ギリギリ突破されない難ダンジョン」を欲しがる → だが Clear を崖に近づける。しかも是正のためバスに信号を送るほど 疑念 が積む。→ **循環↑ vs 攻略安全 vs 秘匿** の三すくみ。

### 8.3 破局を最終的に不可避にするエントロピー源（要決定・§9 R-3）
セッション型の耐久ゲーには「時間とともに難しくなる圧」が要る。候補: 冒険者の成長/人口増、装備インフレ、新フロア解禁、経済の複利。静的マニュアルではいつか捌けなくなる → プレイヤーは仕組みを進化させ続ける。

## 10. v0.3 — 縦切りプロトタイプ仕様（ドラフト / 要確認）

「最小で回る一本」を先に組んで、面白さの核（自動化のデバッグ快感＋盤面の符号設計）を検証する。

### 10.1 スコープ（このスライスに入れる最小要素）
- ゲージ: **2つ**だけ（例: 循環 Flux ／ 攻略進捗 Clear）。利潤・その他は後。
- ガンビット: 条件→行動を**数枠**だけ。冒険者の派遣/引き上げを制御。
- 8ボード: スロット状態を確定（§10.2）。「盤面 → 魔王軍ルーチン」応答表を数エントリ。
- 魔王軍: 1日1回、盤面スナップショットを読んで応答表の該当ルーチンを適用。
- HALT: 1種の緊急介入（§R-6 で定義）。
- 破局: Clear=100%（攻略される）／ Flux が下限割れ（停滞）の2条件。

### 10.2 8ボードの盤面モデル（提案 / R-7）
- 各スロット = { 空 / 色A / 色B / 色C } のいずれか（提案: 3色）。状態空間 = 4^8。
  - 十分広いので、プレイヤーは**その中の一部を自分の符牒（codebook）として使う**。ここが「暗号設計」の遊び。
- 書き込み: ①ガンビットが自動で置く/外す ②プレイヤーが手動 ③HALT が凍結。
- 読み取り: ①プレイヤー（召喚パターン） ②魔王軍（1日1回スナップショット）。

### 10.3 残る未確定（Round 4）
- 🟡 **R-7 盤面の表現力**: §10.2「4状態×8スロット」で良いか（色数・積み重ね・空きの扱い）。序盤は使えるスロット数を絞り最大8まで解禁（D-10）。
- 🟡 **R-8 秘書の分業**: 複数秘書は「担当ドメイン別」（募集係/派遣係/経理…）か「同種を並列増員」か。ルール枠は秘書ごと独立か共有プールか。
- 🟢 **R-9 自己召喚**: 盤面条件による呼び出し以外に、プレイヤーが任意に「様子を見る（＝一時停止に入る）」ことは可能か。可能ならコスト（例: 頻度制限）。
- 🟢 **R-10 緊急窓の緊張**: 「発火→1〜5分」の猶予中は自動運転が続く。この間に現行マニュアルが破局条件を割る可能性＝“到着まで保つ”緊張を設計に使うか。

## 11. ここまでで「成立する骨格」（v0.4 サマリ）

> Director の D-01〜D-10 で、討論段階として**ゲームは一度成立している**。要約:

# 第2部：世界のシミュレーション基盤（討論 v0.5）

> ここが決まると、ガンビット/応答表が「何を感知し、何を動かせるか」の**語彙**が自動的に導ける。まず3層を置く。

## 13. 世界の3層モデル（提案）

### 13.1 冒険者層
- 来訪 → 登録 → パーティ編成 → 潜行 → 帰還（報酬 / 負傷 / 死亡）→ 成長 or 引退 or **離散（旨味低下で他所へ）**。
- 属性案: 強さ/レベル、装備、資金、士気・欲（潜る動機）、生死状態。
- ガンビットが感知しうる条件の源泉＝この層の状態。

### 13.2 ダンジョン層（＝魔王軍の出力ノブ）
- D-05 の「応答表」が設定する**出力**の候補: 各フロアの難度 / モンスター構成 / 罠・宝の比率 / ドロップの質 / 深度（フロア数）。
- 「1日1回」の切替＝この出力プリセットの入れ替え。

### 13.3 経済層
- 冒険者の稼ぎ → 街の消費 → ギルド手数料 ＝ **利潤**。
- **旨味（allure）＝ 期待報酬 / リスク**。高いと人口流入・循環↑、低いと離散（D-07）。

### 13.4 「循環」の正体（提案）
適度な難度で冒険者が「勝ったり負けたり」＝衝突が起き、士気と経済が回る状態。
- **攻略進捗** ＝ 上位パーティがどこまで到達したか（最深到達）。全滅過多→人口枯渇、簡単すぎ→最深到達＝**攻略（最悪の破局）**。

## 14. Round 5 質問書（世界基盤）
- 🔴 **R-11 冒険者の粒度**: 個体シム（各自ステータス）/ 類型コホート（型ごとに束）/ 集計数値。硬派＆多源エントロピーとの相性。
- 🔴 **R-12 ダンジョンの出力ノブ**: §13.2 のどれを魔王軍の制御対象にするか（複数可）。
- 🟡 **R-13 旨味の扱い**: 明示ゲージにするか / 冒険者個々の意思決定に内在させるか（来る・残る・去るを各自が判断）。
- 🟡 **R-14 攻略進捗の定義**: 単一最強パーティの最深到達 / 集団の分布 / 特定条件の達成。
- 🟢 **R-15 死の扱い**: 恒久ロスト / 復活コスト / 負傷離脱のみ。（物語・難度・情緒に効く）

## 15. 世界基盤の決定
- ✅ **D-12 冒険者＝個体シム**: 各自がレベル/装備/士気/資金/生死を持つ。名ありキャラも生成可。ガンビットは個体状態を感知しうる。
- ✅ **D-13 ダンジョン全ノブ**: 魔王軍(応答表)は **難度 / モンスター構成・属性 / 報酬・ドロップの質 / 深度・道順(構造)** の4系統すべてを制御。将来は「自動化ダンジョン系のあらゆる技術」を盛り込む野心。
- ✅ **D-14 旨味＝二層**: マクロ「街の評判」ゲージ（全体の流入/流出の基調）＋ ミクロ個々人の来る/残る/去る判断（揺らぎ）。
- ⚠️ **C-01 スコープ制約（PM旗）**: D-12〜D-13 × D-11(静的Web/個体シム) は負荷と実装量が膨らむ。方針: **構造はタイルでなく抽象グラフ（フロア/分岐ノード）で表現**、個体数は上限管理、豪華機能は**段階解禁（ロードマップ化）**。まず抽象化された薄い版で手触りを取る。

# 第3部：言語（ガンビット＆応答表）の語彙 — 討論 v0.6

> ゲームの「硬派の歯ごたえ」の本体。世界基盤(第2部)から感知/操作できる対象が導ける。以下は叩き台。

## 16. 語彙の叩き台（提案）

### 16.1 ガンビット（秘書側）が**感知**できる条件（源）
- 冒険者個体/パーティ: レベル・装備・士気・資金・負傷・生存見込み・到達フロア・パーティ構成
- 集団/街: 人口・強さ分布・**評判(マクロ旨味)**・流入/流出速度
- 経済: 利潤・手数料収入・資金プール
- ダンジョン観測: 現在の難度プリセット・最深到達・直近の死亡率
- 盤面: 現在の8ボード状態（自分が置いた符号を含む）
- 時間: ゲーム内時刻/日

### 16.2 ガンビットが**実行**できる行動（動詞）
- 募集の開閉・受入条件（どの型を採るか）
- パーティ編成規則（強さ均衡・型混成）
- 派遣可否・対象フロア・**撤退条件**（士気/負傷の閾値で引き上げ）
- 手数料・報酬分配の設定
- 装備/回復/宿の提供（コスト）
- 引退勧奨・除名
- **ボール配置**（裏＝魔王への符号／表＝勇者召喚の武装）

### 16.3 応答表（魔王側）
- 入力＝ボード盤面（1日1回のスナップショット）→ 出力＝ダンジョンノブのプリセット（フロアごとの難度/構成/ドロップ/構造）。
- エントリ＝（盤面パターン → プリセットID）の**ルックアップ**が素直。魔王は「大雑把」＝非対称に単純でよい可能性。

## 17. Round 6 質問書（言語の形）
- 🔴 **R-16 ガンビット言語の形式**: FF12型「条件→単一行動＋優先度順リスト」/ 構造化（if・グループ・サブルーチン・変数）/ ビジュアルノード型。深さとUIを決める。
- 🔴 **R-17 秘書と魔王の対称性**: 両者同じ言語か、非対称か（魔王＝単純ルックアップ）。原案「魔王は大雑把」から非対称が自然か。
- 🟡 **R-18 条件の感知粒度**: 個体を名指しできるか / 集計・閾値ベースか。
- 🟡 **R-19 行動のコスト**: 各行動にコスト/クールダウン/枠消費を付けるか（パズル圧の源）。
- 🟢 **R-20 “ダンジョン技術盛り込み”ロードマップ**: 初期に入れる範囲と、拡張解禁の順序。

## 18. 言語の決定
- ✅ **D-15 ガンビット＝構造化言語**: FF12型の単純リストでなく、**if/グループ/変数**を持つ小さなプログラミング言語。極めて硬派・高表現力。⚠️ 学習/実装コストが重い → **初期は部分集合（条件→行動＋グループ）から始め、変数/サブルーチンは段階解禁**。
- ✅ **D-16 秘書と魔王は非対称**: 秘書＝上記の豊かな言語。魔王＝**盤面→プリセットの単純ルックアップ**（原案「魔王は大雑把」に忠実）。
- ✅ **D-17 コストの二分割**（R-19 の指摘から）:
  - **ロジック/判断**（感知・編成規則・派遣判断・ボール配置）＝ **秘書の容量＝ルール枠**で縛る。
  - **世界に触れる行動**（回復・装備・宿・復活など資源を動かすもの）＝ **ゲーム内経済コスト**で縛る。
  - → 「枠だけだと全行動が実質タダ」問題を回避。ルール枠は“頭脳の容量”、経済コストは“財布”。両者が別軸の圧になる。
